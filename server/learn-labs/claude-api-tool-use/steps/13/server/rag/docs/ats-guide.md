# ATS and keywords

Many companies use an applicant tracking system, or ATS, to store resumes and search them. The ATS reads your file, pulls out text and sorts it into fields such as name, skills and jobs. A recruiter then searches those fields for keywords.

To help the ATS read your resume, use a single column layout, normal headings such as "Experience" and "Skills", and standard bullet points. Avoid text boxes, tables for layout, headers and footers with important details, and text inside images. If the ATS cannot read a part of your resume, that part may as well not exist.

Keywords come from the job post. Read the post and note the skills, tools and job titles that appear more than once. If you truly have a skill, write it using the same words as the post. For example, write "Zendesk" if the post says Zendesk, not only "ticketing software". Never add skills you do not have: interviewers will ask about them.

An ATS does not usually reject resumes by itself. It ranks and filters them, and a person makes the decision. A clear, honest resume that matches the job wins more often than a stuffed one.
