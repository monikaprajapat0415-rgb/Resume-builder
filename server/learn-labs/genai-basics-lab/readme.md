# GenAI Basics Lab (Angular) - solution after lesson {{n}} of {{total}}

A small Angular app with one hands-on exercise for every lesson of the course. Everything runs in your browser. You do not need an API key, a server or an account.

## Run it

1. Install Node.js (version 20 or newer) and run `npm install` in this folder.
2. Run `npm start`, then open http://localhost:4200.

The menu shows one page for every lesson you have completed ({{n}} of {{total}}).

## Layout

- `src/app/lib/` holds the plain TypeScript logic for each exercise (no Angular code), so you can read and test it on its own.
- `src/app/pages/` has one Angular page per lesson.

The models in these exercises are tiny teaching models. They show how the ideas work. They are not real language models, and the numbers they print are not what a real model would give.
